# AWF PVKSAM 当前流程

当前 PVKSAM 只保留一条从原始单分子到 ITO 吸附结构的入口路线：**膦酸 SAM 的 30° 内部扭转网格 → 固定头基 MMFF94s 优化 → P–C 轴共同可行相位恢复与对称感知去重 → ITO 位点 P–C 方位筛选 → 每个骨架只保留一个最低 MMFF94s 单点能姿态 → MACE 表面优化 → 聚类与占地面积选择 → 顺序生长 → H0 约束优化、全局补氢和循环退火**。

ConfSearch 和历史固定表面位点 216 起点路线不再是 PVKSAM 的选项。`--pvksam-front` 只接受 `phosphonate-skeleton-grid`；提供 ConfSearch 或 `legacy-torsion-grid` 配置会明确报错。通用 ConfSearch 工作流仍可独立用于其他任务，不属于 PVKSAM 路线。当前从原始分子开始的入口限定为一个已核实膦酸锚定基团；羧酸和其他化学类型后续遇到时再增加适配器。旧 AWF 不可变 Release 与既有计算结果保留为历史记录，不参与当前路线选择。

本路线尚未对新分子完成两类分子的全链条科学验证。工程回归和 2Nap-Ac 的运行证据只说明已测环节；它们不能保证其他膦酸分子会得到相同候选数或覆盖全部真实吸附态。

## 单一路线

| 阶段 | 操作 | 交接与判据 |
| --- | --- | --- |
| 分子输入与 H0 | 核验带键级的显式 H 单分子 SDF，移除应释放的膦酸质子，保留原子编号映射 | 保存输入、H0、质子和原子映射回执；不从坐标猜键级 |
| 30° 骨架扫描 | 使用逐分子核对的内部四原子扭转路径；固定 P–O 头基，枚举所有唯一 30° 网格组合，自动排除 P–C 轴相位 | 先逐点做高度与分子内碰撞筛选；失败点不进入 MMFF94s 优化；每一点的接受/拒绝原因均留档 |
| 固定头基优化 | 对粗筛通过骨架以 RDKit MMFF94s 优化，固定 P 和三个锚定 O，其余原子可动 | 仅力收敛结构进入下一步；保留未收敛记录但不作为候选 |
| 共同轴相位恢复和去重 | 连续求解 P–C 旋转角，使全部有机原子高度合格且不与 PO₃ 头基碰撞；再以精确分子图对称映射和 1.0 Å 代表半径去重 | 保留全部安全成员、来源能量和簇映射；代表能量是孤立分子 MMFF94s 能量，不是吸附能 |
| ITO 位点安放 | 对每个骨架生成 12 个 P–C 方位（30° 步长），对齐头基后逐个做高度、分子内和周期性 ITO 碰撞筛选 | 所有通过姿态做 MMFF94s 单点能；每骨架只把能量最低的安全姿态交给 MACE。单点阶段不移动原子 |
| MACE 表面优化与筛选 | 在锁定的 ITO 位点和运行环境下优化；按既定表面重原子 RMSD 聚类及能量/占地面积 Pareto 选择 | 每阶段保存输入、模型、软件、参数、输出和哈希；只有通过既定几何与力收敛门的结构进入后续 |
| 顺序生长 | 从选中候选按 `cohesive-frontier + continuous-snap` 生长，三齿、双齿完成后开启动态 CN5 单金属补位 | 位点筛选默认排除吸附前 CN≥6 的金属（O 邻居截断 2.7 Å，最多 CN5）；不固定最终分子数 |
| H0 优化、补氢和退火 | 使用本页后半部分规定的统一约束、全局补氢和逐轮停止检查 | 未收敛或检查失败即停并保留现场；不静默放松判据 |

### 骨架网格、筛选和去重

先用保持手性的单一刚体变换将三个锚定 O 放在 `z=0` 平面并使 P 位于正 z 一侧；不单独移动或压平 O。每条四原子扭转路径须按当前分子的原始 1-based 原子编号审核。对 `k` 条内部扭转，30° 网格有 `12^k` 个唯一周期组合；P–C 中心键不增加维数，其自由相位留给后面的 ITO 安放。

每个网格点在优化前做碰撞检查。只排除直接成键原子对；其余 H–H、H–重原子、重原子–重原子最小距离依次为 1.2、1.4、1.8 Å。随后连续求 P–C 整圈可行区间：所有 C 侧原子（包含 H）须满足 `z≥0`，并在同一个轴角同时避开固定 PO₃ 头基。不能用离散少数轴角的失败来推断整圈不可行。明显自碰撞或共同高度/头基净空无解的构象直接剔除，不进入力场优化。

通过初筛的候选以 RDKit `MMFF94s` 优化，P 和三个锚定 O 固定。2Nap-Ac 案例以可动原子最大力 `0.03 eV/Å` 为收敛门，每 250 步检查一次，最多请求 5000 步；这些数值是已运行案例设置，不是所有体系已标定的最佳设置。优化后重新连续求解共同轴相位，取最宽可行圆弧的中点，并复核写出结构的高度、净空和头基固定。

去重只比较有机重原子形状，排除 P 和三个锚定 O。比较时将 P→首个 C 轴用保持手性的旋转对齐，再消去共同 P–C 方位角；不做任意 Kabsch 拟合。按原优化 MMFF94s 能量从低到高处理，使用原始 H0 重原子图的精确对称映射；距已选代表的逐原子三维 RMSD 不超过 1.0 Å 就归入最近代表，否则成为新代表。文件坐标、原子编号和全部安全成员保持原样。该阈值定义骨架形状代表，不证明成员处于同一力场能谷。

### ITO 位点单姿态选择与表面优化

将各骨架放到登记 ITO 位点时，保留明确的锚定 O—金属映射。每骨架绕 P–C 轴取 0° 至 330°、每 30° 一个姿态。先以 PO₃ 头基刚体拟合 RMSD ≤0.50 Å 作为当前复用几何门，再要求全部非锚定 SAM 原子（含 H）不低于三个锚定 O 的平均高度，并通过分子内与周期性 ITO/表面 H 碰撞审查。拟合容差是已用案例复用值，尚未跨体系标定。

对同一骨架全部通过的方位计算同一 H0 键图上的 MMFF94s 单点能，只选最低者作为 MACE 起始姿态；此处不优化坐标。气相单点能只是缩减 MACE 起点的规则，不代表 ITO 上吸附能排序。若无安全方位，记录为无可安放候选并停止该骨架，不放宽筛选条件。

2Nap-Ac 的实测过程是：20,736 个骨架网格点，3,655 个通过优化前几何筛选；优化后 2,765 个通过共同 P–C 相位与净空审查，按对称感知规则得到 121 个代表；每个代表生成 12 个 ITO 方位，共 1,452 个姿态，1,292 个通过表面前筛，每个骨架择一进入 MACE；该次 MACE 有 121 个有效结构、81 个表面几何簇，最终 Pareto 选择 7 个。以上仅为该分子和登记位点包的证据，不是新分子的预期固定计数。

## 生长与位点规则

PVKSAM 生长方法固定为 `cohesive-frontier + continuous-snap`；`uniform` 已删除。默认阶段为三齿耗尽、双齿耗尽、动态 `cn5-uncovered` 单金属补位。六配位排除默认开启：只数吸附前基底 O，金属—O 截断 2.7 Å，允许最多 5 个邻近 O。H0 交接前再复核每条已映射金属—锚定 O 约束，避免位点映射漂移。此位点筛选不限制后续退火中的局部配位变化。

生长沿用已登记配置：构象上限 10、头基拟合容差 0.50 Å、前沿搜索半径 4.0 Å、周长/面积/接触容差分别 10%/20%/20%、能量容差 0.03 eV、侧接触半径系数 1.10；动态单金属姿态旋转步长 30°、平移偏移 `[-1,-0.5,0,0.5,1] Å`，种子 340501。最终覆盖数由可行候选决定，不硬编码为 82。生长的具体执行仍需读取当前维护脚本默认项并把完整配置写入运行清单。

## H0 优化、全局补氢和循环退火

原子布局为基底在前、等长 SAM 块在后；补氢插入基底与 SAM 之间。每个 SAM 至少有一条来自实际吸附映射的金属—锚定 O 约束。每个 SAM 具体原子数、基底数、固定层及映射都从本次清单读取；旧 N82 数值只是历史示例。

- 从刚吸附完成且未断裂的完整 H0 生成并封存 SAM 内部键、界面对和每个适用 P 的四面体约束。SAM 重原子内部键弹簧常数 20 eV/Å²，含 H 键 10 eV/Å²，目标长度固定为第一次优化前的 H0 键长。
- 金属—O 单侧拉长约束为 `U=0.5×100×max(r-r0,0)^2`，单位 eV、Å；保留吸附生长记录中的金属身份和目标长度。单齿、双齿、三齿只约束实际登记的键，不依齿数虚构额外键。
- 每个 P 必须从第一次优化开始保持完整 3O+1C 四面体约束。六个配体角弹簧常数 20 eV/rad²，目标来自完整 H0；P—基底 O 在 2.20 Å 内加 100 eV/Å² 单侧排斥。适用 P 不可跳过。羧酸不使用 P 角约束，但原始分子到吸附的路线当前不支持羧酸。
- 全局 MILP 按本次 SAM 数分配表面 H：膦酸每分子 2 个，羧酸每分子 1 个；表面 O 全局唯一分配。新增表面 OH 在后续优化和 MD 中不加键、角或位置约束，允许自由移动和质子转移。
- 每个 H0 和补氢后优化阶段使用 `fmax=0.01 eV/Å`、`maxstep=0.02 Å`、最多 2000 步。未收敛或约束审查失败时不继续到下个阶段。
- 循环退火逐轮执行 `300→500→300 K`，1500 步、2 fs（3 ps）；升温/保温/降温分别 250/500/750 步。H 积分质量按已采用的 4 amu 质量缩放处理，输出前恢复物理质量。每轮后优化并检查力收敛、适用 P 四面体和异常短接触；MD 期间每 100 步检查 P。
- 从第 5 轮起逐轮检查最近 5 轮最佳能量；累计改善小于 `0.005 eV/SAM` 且力与几何门均通过则收敛。20 轮是复核上限，达到上限不等于收敛。保存完整能量/RNG 历史和最好结构。
- 不做三 O 投影三角形规则、不再检查非锚定原子高度或完整分子拓扑；短接触诊断仍保留。`physical_interface_pass` 保留为 `null`，不误称为旧物理晋升检查通过。

## 运行交接和证据

`orchestrate_md_pipeline.py --pvksam-front CONFIG --plan` 生成封存计划；`--execute --front-through cpu` 只完成 H0 标准化与 30° 骨架 CPU 粗筛，并在 `awaiting_fast_skeleton_optimization` 交接。固定头基 FF、共同轴相位/去重、ITO 方位筛选、MACE 和生长按各阶段现有入口显式续接；不能把 CPU `prepared` 结果说成吸附层已完成。H0 以后使用 `--pvksam-post post.json --plan/--execute`。

每阶段保留输入/输出哈希、脚本与运行时身份、参数、候选接受/拒绝原因和运行清单。程序错误修复后使用新输出目录。正式科学运行先查询匹配的程序运行指南；此工作流不隐含安装软件、下载模型或开展额外全链条验证。用户授权的后续新分子遇到失败时，保存失败证据、修正现有实现并发布新的不可变 AWF Release；不原位改写旧 Release。
